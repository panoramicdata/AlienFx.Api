# Security Policy

## Supported Versions

If a vulnerability is found in our software, we will issue an update to the latest available public release at the time the vulnerability is identified.

We recommend you always use the latest version of this package to benefit from up-to-date bug fixes and security patches.

## Reporting a Vulnerability

To report an issue, complete this form: https://panoramicdata.com/support

We will acknowledge valid submissions, provide a ticket reference and give updates on the issue.
